无约束：315（睡袋 + 食物 + 水具，1基 [3, 4, 5]）

===== 情形一：必投“帐篷”（原最优组合里没有它）=====
必投 帐篷（300g, 90）：
  最优 290（帐篷 + 食物 + 水具，950g，1基 [1, 4, 5]）
  穷举核对：290，1基 [1, 4, 5] → 一致

===== 情形二：必投“睡袋”（原最优组合里已有它）=====
必投 睡袋（350g, 115）：
  最优 315（睡袋 + 食物 + 水具，1000g，1基 [3, 4, 5]）
  穷举核对：315，1基 [3, 4, 5] → 一致

===== 情形三：必投“炉具”=====
必投 炉具（200g, 60）：
  最优 295（炉具 + 睡袋 + 食物，950g，1基 [2, 3, 4]）
  穷举核对：295，1基 [2, 3, 4] → 一致

===== 情形四：必投“帐篷”但容量只有 200g（不可行）=====
必投 帐篷（300g）：限重 200g 时装不下 → 无可行解

===== 解释 =====
必投约束把“可选题”变成“必选题”：先无条件占用一份重量和重要度，
剩余容量变小，原最优组合可能被挤掉。必投“帐篷”时，剩余 700g 最多
再拿 食物+水具（200），总计 90+200 = 290，比无约束的 315 少 25；
必投“睡袋”时它本来就在原最优组合里，所以最优值仍是 315，组合不变。
